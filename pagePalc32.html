PALC 32
•VIEW LIVE TECHNOLOGY CUSTOM HARDWARE OVERVIEW PALC 32 is a programmable arithmetic and logic controller for advanced processing capabilities, with 30 input ― output board-to-board interface. HARDWARE FEATURES The PALC 32 supports four interchangeable MCU with different Flash, EEPROM, and SRAM capacities : • ATmega164P • ATmega324P • ATmega644P • ATmega1284P The MCU onboard operarting 16 MHz frequency at low power consumption. MCU features GPIO, USART, SPI, TWI, PWM, ADC, interrupt, and pin change interrupt peripherals. The board features 2 power supply port, 32 GPIO pins organized into 4 8-pin ports along with dedicated +5 V and GND connections for powering peripheral, and provides 1 ISP programming interface for upload/download firmware. A robust LDO power supply based on LM2940 linear regulator and an MJE15033 transistor support demanding power requirements, produces low noise, and accept wide input voltage range. The board features 4 M3 mounting points. PERFORMANCE The PALC 32 designed for computationaly intensive and real-time embedded applications. The board linear power supply provides wide input range +5 V to +26 V, low electrical noise, silent operation, and stable +5 V output voltage. RESULTS The PALC 32 provides a versatile hardware platform for wide range complex embedded systems. Its combination of efficient processing, extensive input ― output, and robust architecture.
