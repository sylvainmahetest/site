PROTOTYPE 001
Radio control
•VIEW LIVE TECHNOLOGY CUSTOM HARDWARE - CUSTOM SOFTWARE OVERVIEW Radio control is a high-performance human-machine interface platform for multi-domain control, featuring fully user configurability, many user-defined parameters, and multidirectionnal wireless connectivity. HARDWARE FEATURES The controls and interface features 2 dual-axis joysticks, 4 trim controls, 4 configurable switches, 1 configurable rotary control, 1 menu rotary control, 1 menu button, and an integrated display and buzzer for intuitive operation. The wireless connectivity interface includes an high sensitivity external 2.4 GHZ omnidirectionnal antenna for maximize range, and low power tranceiver to extend battery life. The wired connectivity interface includes an external programming connector for firmware update. The fully machined metal enclosure is rugged and provides electromagnetic shielding. The wooden section adds warm and natural feel. SOFTWARE FEATURES The channel configuration and calibration functions provide advanced channel adjustments, including trims, range, curves, reversing, and special functions, enabling flexible configuration and efficient operation. All potentiometers can be calibrated to optimize their operating ranges. The setup and system management functions support customizable transmitter and receiver parameters, triggerable timer alarms activated either by a switch or the throttle stick, battery alarms for both the transmitter and receiver. The software automatically adapts the transmitter's configuration to the connected device, ensuring that only the most relevant parameters and settings are available for each application and domain. The safety operation provide failsafe protection and watchdog monitoring for both the transmitter and receiver. The radio communication protocol provides CRC-based error detection and uses device identification to ensure reliable communication between the transmitter and receiver, preventing cross-connection with other devices. The transmitter features a menu lock to prevent accidental changes during operation. •SOFTWARE DOWNLOAD PERFORMANCE The two dual-axis joysticks features 10-bit resolution and uses post-ADC processing to achieve high precision and low latency, real-time computing handled by the MCU, radio communication system uses 32-bit frames with low-latency and redondancy to improve communication reliability. RESULTS The prototype demonstrates a versatile and user-configurable radio control platform combining intuitive operation, flexible configuration, and reliable wireless communication. Operationnal demonstrations conducted at airfields allowed observers to see the prototype in operation and appreciate its pratical capabilities and potential for real-world applications.
