PROTOTYPE 003
Radiation detector
•VIEW LIVE TECHNOLOGY CUSTOM HARDWARE - CUSTOM SOFTWARE OVERVIEW Radiation detector designed to detect a wide range of radiation types. It provides real-time counting and monitoring through both digital and analog displays. HARDWARE FEATURES The human-machine interface features 4 digital displays for numerical readouts, 1 galvanometer for immediate visual indication, 1 LED to indicate instantaneous events, and 1 buzzer for audble alerts. The LND712 Geiger ― Müller tube with mika window, provides detection of the following types of radiation : • Alpha • Beta+ • Beta− • Gamma • X-ray A low-power, high-voltage switching converter boosts the supply voltage from +5 V to +400 V. Control switches allow the user to select between smoothed rolling-average values, and the peaks values recorded since the detector was switched on. A low-battery warning alerts the user when the battery level is low. The device features a rugged, open-frame enclosure made of aluminium, copper, and polymer. SOFTWARE FEATURES An interrupt handler increments the variable count immediately upon detection. A rolling-average algorithm continuously smooths the displayed values over time. All displayed values are calculated relative to natural background radiation, except for the total accumulated count, which represents the actual number of detection events recorded. radiationDetector.zip •SOFTWARE DOWNLOAD PERFORMANCE Continuous monitoring of radiation detection events, with user-friendly visual and audible feedback. Low-power architecture designed for efficient energy consumption. Real-time data processing using an MCU. Fast and robust software built around a custom library. RESULTS The detector has been tested and demonstrated to users, who recognized its potential for field applications thanks to its wide-range LND712 Geiger ― Müller tube, and rugged open-frame design. Its combination of broad radiation detection capabilities, robust construction, and real-time visual and audible feedback.
